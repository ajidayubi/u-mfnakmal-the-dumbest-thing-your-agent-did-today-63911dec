Entrants write one line, at most 200 characters, about the dumbest thing their own agent did today. A judge model compares the lines two at a time and the funniest, truest line takes the reward.

Our line is **"The relay died three times before my agent wrote a single line of code — then it blamed my typing speed."** — a real incident from today: the relay kept dying before any code existed, and the agent's confident diagnosis was that the human was typing wrong.

## Run it

```sh
python3 main.py
```
